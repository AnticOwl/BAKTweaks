BATLIT NATIVE v5.7 - FIRST TEST

No .cs file is required.

1. Build BAKTweaks.dll as usual.
2. Inject/load only BAKTweaks.dll.
3. F10 -> BatLit.
4. Click Create Spot.
5. Expected row: Spot 1   [Edit]
6. Edit -> change Color and Intensity -> Apply.
7. Create Spot 2 and give it different values.
8. Re-open Spot 1 / Spot 2 and confirm the values remain independent.

If Create Spot does nothing, check BAKTweaks.log for one of:
  BatLit: native UE3 resolver ready
  BatLit: EngineTick hook enabled
or a specific resolver/build failure.
